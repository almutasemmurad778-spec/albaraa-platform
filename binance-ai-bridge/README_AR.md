# Binance × GPT — تطبيق أندرويد للتحكم في حساب Binance عبر الذكاء الاصطناعي

**الحالة (الإصدار 1.1):** مشروع أندرويد يتضمن كود المصدر والإعدادات لبناء APK متوافق مع Android 15 (targetSdk 35). **لم يُبنَ APK في هذه الجلسة لعدم توفر أدوات Android SDK وGradle محليًا، ولم يُختبر على حساب Binance حقيقي.** لا تعتبره تطبيقًا مدققًا للاستخدام بأموال حقيقية.

## إمكانات التطبيق

- واجهة محادثة عربية على هاتف أندرويد. تستخدم OpenAI API (نموذج `gpt-4.1-mini`) للتفسير وصناعة استدعاءات الأدوات.
- أداة Binance REST عامة لتشغيل طلبات `GET`, `POST`, `PUT`, `DELETE` للمسارات الموثّقة تحت `/api/v3/`, `/sapi/v1/`, `/sapi/v2/`, `/fapi/v1/`, `/fapi/v2/`, `/dapi/v1/`, `/dapi/v2/` بحسب توفر الخدمة وصلاحيات الحساب.
- تمكين عمليات الحساب التي تتيحها مفاتيح Binance: قراءة الأرصدة، التداول Spot، تحويلات، بعض خدمات الهامش والعقود، والسحب عند دعم Binance والموافقة على الصلاحية المطلوبة.
- توقيع HMAC SHA-256 لمعاملات Binance على الهاتف محليًا. مفاتيح Binance لا تُرسل إلى نموذج الذكاء الاصطناعي؛ تُرسل البيانات المسترجعة ونتائج العمليات كي يتمكن المساعد من الإجابة.
- يتطلب التطبيق **موافقة صريحة داخل الهاتف لكل طلب POST/PUT/DELETE** قبل إرساله، حتى لو فُعّلت الصلاحيات في حساب Binance.
- زر اختياري لحفظ الربط **مشفّرًا على الهاتف باستخدام Android Keystore (AES-GCM)** داخل مساحة التطبيق الخاصة، مع زر لمسح الربط. يمكن عدم الحفظ وإدخال المفاتيح في كل جلسة. لا توجد أعمال خلفية أو تداول آلي بعد إغلاق التطبيق.
- زر اختبار الاتصال بحساب Binance قبل بدء استخدام المساعد.
- أي عملية كتابة (POST/PUT/DELETE) تتطلب موافقة يدوية واضحة حتى عند تفعيل صلاحيات التداول والتحويل والسحب.
- الـ endpoints ليست مفتوحة على خوادم أخرى: host Binance محدد داخل التطبيق، ورابط OpenAI ثابت. لا يقبل إلا مسارات Binance الرسمية المحددة.

## ما لا يفعله

1. **لا يربط نفس محادثة ChatGPT المفتوحة بهذا التطبيق.** يوفر مساعدًا مستقلًا عبر OpenAI API، ويتطلب مفتاح OpenAI API مدفوعًا منفصلًا (اشتراك ChatGPT Plus لا يساوي اشتراك OpenAI API).
2. **لا يتصل بالمحفظة Web3 MPC/Agentic Wallet نفسها** عبر Exchange REST API؛ لهذه المحفظة مسار Binance Agentic Wallet/MCP الرسمي.
3. **لا يتخطى شروط Binance أو الحدود التقنية**: نوع الحساب، شروط البلدان، الصلاحيات، IP allowlists، صلاحيات السحب، قيود التداول والهامش والعقود.
4. ليس تغطية مكتملة ومتحققًا منها لكل واجهات Binance؛ الأداة عامة ويجب أن يختار النموذج مسارات ومعاملات صحيحة، وقد يخطئ أو يفشل. بعض المسارات تتطلب أنواع مفاتيح أو صيغ مصادقة مختلفة عن HMAC المستخدم هنا.
5. ليس جاهزًا لتأمين مبالغ حقيقية؛ الكود نموذج تعليمي لا يخضع لتدقيق اختراق أو صلاحية إنتاج.

## بناء APK على كمبيوتر

1. ثبّت Android Studio مع Android SDK Platform 35 وJDK 17 واتصال بالإنترنت لتنزيل Gradle ومكونات البناء. نسخة المشروع تعتمد على واجهات Android الأصلية وتستخدم Android Keystore بلا مكتبات خارجية إضافية.
2. افتح مجلد `Binance_AI_Bridge` كمشروع Gradle. يتطلب Android Gradle Plugin 8.7.3 / Gradle 8.9.
3. من **Build → Build APK(s)** أنشئ `app/build/outputs/apk/debug/app-debug.apk` وثبّته بعد مراجعة الشيفرة.
4. على الهاتف: أدخل **مفتاح OpenAI API** و**مفتاح Binance HMAC API Key وAPI Secret** داخل التطبيق، ولا ترسلها إلى ChatGPT في هذه المحادثة. يمكنك استخدام زر حفظ الربط المشفر لتجنب إعادة إدخالها، لكن لا تفعل ذلك على هاتف مشترك.
5. ابدأ باستعلام بسيط لا يحرّك أموالك، مثل `اعرض سعر BTCUSDT`، ثم اختبار قراءة أرصدتك قبل أي عملية كتابة.
6. راجع نافذة التأكيد بالكامل، بما فيها المسار والمعاملات، قبل تنفيذ أي عملية مالية.

## طريقة ربط Binance رسميًا بمساعد MCP

- Binance MCP: https://agent.binance.com/mcp/agentic
- توضيح الصلاحيات: https://www.binance.com/en/support/faq/detail/7a6e676e36fb455d96478932cb12d9f3
- Binance Agentic Wallet: https://developers.binance.com/en/docs/products/agentic-wallet/welcome

الرابط الرسمي لـ Binance MCP يتيح القراءة والتداول والتحويلات الداخلية في حساب Agentic المعزول، **ولا يدعم السحب الخارجي**. إمكانات ربط هذا الرابط داخل ChatGPT نفسه تعتمد على نوع خطة ChatGPT وإمكانية إضافة custom MCP server؛ إضافة خوادم MCP المخصصة غير متاحة مباشرة من تطبيق الهاتف وقت إعداد هذه النسخة.

## تنبيهات مهمة

- تفعيل صلاحية السحب في مفتاح Binance قد يكون غير متاح أو يشترط IP ثابت/قائمة بيضاء، ولا يمكن للتطبيق تجاوز ذلك.
- السحب/التداول الآلي قد يسبب خسارة أو نقل أموال غير مقصود؛ راجع الأوامر بدقة، لا تضع مدخراتك بالكامل في حساب التجربة.
- معلومات الحساب والاستعلامات المسترجعة تُرسل إلى OpenAI كبيانات أدوات، ولو أن بيانات الاعتماد نفسها لا تُرسل.
- لا تمنح الأذونات أو توقّع معاملات نيابة عن أحد غيرك. لا تضع كلمة مرور Binance أو رموز 2FA أو Seed Phrase في هذا المشروع.
- لا تستخدم مفتاح API فعليًا قبل اختبار النموذج وفحص المصدر مع مطور أمن أندرويد.

## إنشاء APK من الهاتف فقط عبر GitHub Actions

إذا لم يكن لديك كمبيوتر، ارفع **محتويات مجلد المشروع بهيكله الصحيح** إلى **مستودع GitHub خاص** (لا ترفع ملف ZIP وحده). ثم افتح تبويب **Actions** واختر **Build Android APK → Run workflow**. بعد نجاح البناء، افتح التشغيل ونزّل Artifact باسم `Binance-AI-Bridge-debug-apk`، ثم استخرج منه `app-debug.apk` وثبّته. تحتاج حساب GitHub واتصالًا بالإنترنت، وقد يخضع التشغيل لقيود حساب GitHub. **لا ترفع مفاتيح Binance أو OpenAI إلى المستودع**؛ لا يحتوي المشروع على أي مفاتيح.

> ملاحظة: مسار Android Studio قد يحتاج Gradle 8.9 مثبتًا محليًا أو إنشاء Gradle Wrapper للمشروع (ملف wrapper التنفيذي غير موجود في هذه الحزمة). خيار GitHub Actions يهيّئ Gradle آليًا.


## توافق Android 15

- الإصدار: **1.1.0**، `compileSdk 35`، `targetSdk 35`، `minSdk 26`.
- لا يطلب إلا إذن الإنترنت، لا يطلب إذن رسائل SMS أو جهات الاتصال أو التخزين أو الوصول للصور.
- يدعم حواف الشاشة في Android 15 ويمنع لقطات الشاشة داخل التطبيق؛ بإمكانك مسح الربط المحفوظ.
- APK الذي ينتجه GitHub Actions هو **نسخة Debug موقعة آليًا للتجربة**، وليس إصدارًا نهائيًا منشورًا على Google Play. لا تدخل مفاتيح تتمتع بصلاحية سحب أموال قبل المراجعة الأمنية والتجربة الدقيقة.

## طريقة تحويله إلى APK من الهاتف

1. بعد ربط GitHub وإنشاء مستودع خاص، ارفع ملفات المشروع **بنفس بنية المجلدات**.
2. من تبويب **Actions** شغّل `Build Android APK`.
3. عند ظهور نجاح في البناء، نزّل المرفق `Binance-AI-Bridge-debug-apk` من صفحة التشغيل.
4. فك ضغط الملف، واضغط `app-debug.apk` ثم اسمح للتطبيق الذي فتح الملف بتثبيت التطبيق إذا طلب Android ذلك.
5. افتح التطبيق، أدخل مفاتيح API، واختبر الاتصال للقراءة قبل استخدام أي عمليات مالية.

**تنبيه:** نجاح البناء في GitHub غير مضمون قبل التنفيذ الفعلي، ولا يعني تدقيق التطبيق أو سلامة التداول بأموال حقيقية.
